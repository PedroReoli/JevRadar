- filtros por status e fonte sincronizados na URL da interface;
- read model limitado a dez execuções por página, com teto de 50 no contrato nativo;
- controles acessíveis de página anterior e próxima;
- correção automática de páginas acima do total disponível;
- endpoint autenticado `GET /v1/collection-history` documentado no Swagger;
- índices dedicados para status, data e fontes das execuções;
- compatibilidade preservada para `GET /v1/collections` e consumidores internos existentes.

## Dependências externas não simuladas

- o histórico só cresce quando o usuário executa coletas reais com as fontes habilitadas;
- resultados reais dependem de coleta contínua, disponibilidade das fontes e chave Jev do usuário;
- publicação assinada e atualização automática exigem certificado, chaves e endpoint HTTPS definitivo.
