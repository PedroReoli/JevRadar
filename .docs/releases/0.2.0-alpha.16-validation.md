- endpoint autenticado `GET /v1/calibration-readiness` incluído no mesmo marco integrado.

- o histórico só cresce quando o usuário executa backtests com dados reais suficientes;
- resultados reais dependem de coleta contínua, fontes habilitadas e chave Jev do usuário;
- publicação assinada e atualização automática exigem certificado, chaves e endpoint HTTPS definitivo.
