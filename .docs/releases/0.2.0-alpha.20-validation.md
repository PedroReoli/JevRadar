## Dependências externas não simuladas

- sinais reais dependem de coleta contínua, fontes disponíveis e chave Jev do usuário;
- os filtros foram validados com contratos e fixtures locais, não com chamadas pagas ao Jev;
- a API local permanece desabilitada por padrão e exige ativação e token pelo usuário;
- publicação assinada e atualização automática exigem certificado, chaves e endpoint HTTPS definitivo.
